    Deployment Models

    Two Profiles. One Unified Ecosystem.

    Tailor your lab deployment according to internet speed, local storage, and installation workflows.

    Offline Capable

    Full Live/Desktop ISO

    Complete turnkey installation media containing the offline desktop environment, Calamares graphical installer, base packages, and Veyon service.

    • Target Directory:profile/
    • Volume Label:CATTENY_YYYYMM
    • Compression:zstd level 19
    • Desktop Stack:KDE Plasma 6 / XFCE4
    • Installer:Calamares GUI + Offline
    • Veyon Daemon:Pre-installed & Active
    • Typical ISO Size:~2.4 GB
    mkarchiso -v -w /tmp/build -o ./out ./profile/
    Lightweight Base

    Minimal Netinstall ISO

    Compact bootable base image designed for mass PXE netboot or fast USB flashing. Fetches fresh upstream packages dynamically during the setup phase.

    • Target Directory:profile-netinstall/
    • Volume Label:CATTENY_NET
    • Compression:zstd level 19
    • Desktop Stack:Dynamic Network Pull
    • Installer:Network Bootstrap
    • Veyon Daemon:Pulled at Installation
    • Typical ISO Size:~820 MB
    mkarchiso -v -w /tmp/net-build -o ./out ./profile-netinstall/

    Calamares Modular Execution Pipeline

    Calamares bifurcates system installation into an interactive user presentation queue and an isolated chroot execution queue governed by settings.conf.

    PHASE 1: PRESENTATION QUEUE (UI)
    1. welcome 2. keyboard 3. partition 4. users 5. packagechooser 6. summary
    ↓
    PHASE 2: GLOBALSTORAGE SERIALIZATION

    GlobalStorage.set("packagechooser_packagechooser", ["libreoffice-fresh", "thunderbird", "vlc", "steam"])

    ↓
    PHASE 3: CHROOT EXECUTION QUEUE (/target)
    mount fstab machineid initcpio packages (pacman execution) bootloader (grub/syslinux) services-systemd (veyon) umount

    Getting Started

    Flashing & Installation Guide

    How to burn the Catteny ISO to a USB flash drive or setup automated PXE boot.

    Use the command below to burn the ISO directly to your USB thumb drive in RAW image mode. Make sure to specify the correct block device (e.g. /dev/sdb):

    RAW BLOCK DEVICE WRITE BASH 
    sudo dd bs=4M if=Catteny-0.1-x86_64.iso of=/dev/sdb conv=fsync oflag=direct status=progress

    Ventoy is the recommended utility for computer lab administrators:
    1. Format your USB drive with Ventoy (ventoy.net).
    2. Simply copy Catteny-0.1-x86_64.iso into the Ventoy USB partition.
    3. Boot any UEFI or legacy BIOS workstation directly from the menu.

    When using Rufus on Windows:
    1. Select your USB drive and point to the Catteny ISO image.
    2. Partition scheme: GPT for modern UEFI or MBR for legacy BIOS.
    3. Crucial: When prompted, choose "Write in DD Image mode" to ensure Archiso hybrid partitions are written correctly without corruption.
